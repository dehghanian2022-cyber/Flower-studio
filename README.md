# Bloom 🌷

A modern and responsive flower studio website built with HTML and CSS.

## Features

- Responsive design for desktop and mobile
- Clean and elegant floral-themed UI
- Navigation bar
- Hero section
- Flower cards
- About section
- Contact form
- Footer
- CSS hover effects and transitions
- Flexbox
- Media Queries

## Technologies

- HTML5
- CSS3
- Flexbox
- CSS Media Queries

## Project

Bloom is a simple flower studio website designed with a soft, minimal, and elegant visual style.
